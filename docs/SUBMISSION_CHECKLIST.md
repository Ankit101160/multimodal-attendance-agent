# SkillWallet submission checklist

- [ ] Run everything once locally (`setup.bat` -> `python main.py ...` -> `streamlit run app.py`)
- [ ] Test on at least one real classroom/friends video (with consent) and keep the outputs in `results/`
- [ ] Push to GitHub (public repo): code, `sample_data/`, `results/`, `docs/`, README
- [ ] Record the demo video (`docs/DEMO_VIDEO_SCRIPT.md`) and upload as unlisted link
- [ ] Add **GitHub link** and **Demo link** (Overview/Workspace -> "Add Github Link" / "Add Demo Link")
- [ ] Fill the **Project Report** using the project document provided in the SkillWallet workspace (mandatory)
- [ ] Kanban: move every card To Do -> In Progress -> Review
- [ ] Fill the Conclusion section of the workspace
- [ ] Attend the Grand Assessment
